# Mohamed Aabi Jees — Portfolio

A responsive, single-page portfolio built with React, TypeScript, and Vite.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The static production output is written to `dist/`. Deploy that directory to a static hosting provider that supports Vite-built sites.
